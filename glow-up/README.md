# GLOW UP

A neon-city "looks and aura" Roblox game. Start as a **Rookie**, build your look, train your
stats, out-glow other players in duels, and climb to **Eternal**.

Everything (world, wardrobe items, UI, sounds) is generated by script, so there is nothing to
import or upload.

## The loop
| System | What you do |
|---|---|
| **Shards** | Walk the plaza to collect Aura shards. Chain pickups for a multiplier. |
| **Training** | Three stations (Gym, Style Studio, Charm Lounge): hit the gold zone in a 5-rep timing minigame to raise Power / Style / Charm. |
| **Wardrobe** | 25 cosmetics (halos, crowns, wings, masks, auras, trails) in 5 rarities. Everyone sees what you wear. Each item adds Glow Score and Aura per second. |
| **Crates** | Street / Neon / Icon crates. Duplicates level an item up to 5 stars. Pity timers guarantee good drops. |
| **Duels** | "Mog" duels: a 7-second tap battle vs another player or the Mogger Bot. Glow Score gives an edge, speed can upset. Losing costs nothing. |
| **Runway** | Strut the central runway for steady Aura that scales with your Glow Score. |
| **Ranks** | Rookie → Rising → Smooth → Sharp → Radiant → Certified → Icon → Legend → Mythic → Eternal. Shown on a nameplate above your head. |
| **Rebirth** | Reset Aura/stats/upgrades, keep every cosmetic, gain +25% Aura and Glow forever. |
| **Quests, Daily, Events** | Endless small goals, a 7-day streak, and Golden Hour / Shard Storm / Duel Frenzy / Runway Night every few minutes. |
| **Idle income** | Your look keeps earning while you're away (50%, up to 2 hours). |
| **Hall of Icons** | In-world board of the highest Glow Scores on the server. |

Controls: **E** interact, **Space** hit the training zone / tap in duels, **M** open the menu.

## Install (easiest): open the ready-made place
1. Download `GlowUp.rbxl` (or `GlowUp.rbxlx`, same thing in a text format).
2. Double-click it, or in Roblox Studio use **File > Open from File** and pick it.
3. Press **Play**. Everything is already in the right place.

`GlowUp.rbxl` is built from `src/` with Rojo (`rojo build default.project.json -o GlowUp.rbxl`),
so rebuilding after editing any file is one command. You can also run `rojo serve` and connect
from Studio to live-sync edits.

(Studio's Command Bar cannot take pastes this large, so there is no paste-installer.)

## Install (alternative): by hand
Create these in Explorer and paste each file's contents into the matching script:
- `ReplicatedStorage > Shared` (Folder) with ModuleScripts `Config`, `Util`, `Audio`, `UI`
- `ServerScriptService > Main` (Script) with a `Modules` Folder of the server ModuleScripts
- `StarterPlayer > StarterPlayerScripts > Client` (LocalScript) with a `Modules` Folder of the client ModuleScripts

## Layout
```
ReplicatedStorage.Shared      Config, Util, Audio, UI        (data, helpers, design system)
ServerScriptService.Main      Script + Modules folder        (Data, Stats, Cosmetics, Shards, Training,
                                                              Crates, Duels, Quests, Daily, Events,
                                                              Runway, Shop, Nameplate, Board, World)
StarterPlayerScripts.Client   LocalScript + Modules folder   (Fx, Toasts, Menu, Hud, 6 tabs, TrainingUI,
                                                              DuelUI, Orbs)
```
All balance (ranks, costs, odds, rewards, events) lives in `src/shared/Config.luau`.

## Saving
Progress saves with DataStores. In Studio: **File > Publish to Roblox**, then
**Home > Game Settings > Security > Enable Studio Access to API Services**. Until then the game
runs normally but does not save.

## Audio
Sounds are built from short sounds that ship with Roblox, so the game works with no uploads.
If a sound file is missing from your Roblox version the Output window says so; paste any sound id
from the Creator Store into `Config.Sounds`, or set `Config.MusicTrackId` to a looping song.

## Tests
`tests/` contains a Roblox mock and scenario runners (Luau CLI): `build_server_test.py`,
`build_client_test.py`. The mock validates every property, class and enum
name against Roblox's official API dump.
