# CLAUDE.md

This repository holds *Burn to Become* by Bazooka (`burn-to-become/`): the manuscript source, illustrations, build scripts, finished book and cover files, and the `btb` Field Manual CLI (`burn-to-become/engine/`).

When the user asks to apply the book to their life, goals, routines or tools, follow `burn-to-become/ENGINE.md`.

- Rebuild the book: `burn-to-become/build/build_all.sh` (see `burn-to-become/README.md`).
- Test the CLI: `cd burn-to-become/engine && python -m unittest discover -s tests`.
