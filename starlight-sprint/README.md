# ✨ Starlight Sprint

A tiny, magical, one-more-orb Roblox game. Everything (world, lighting, orbs, UI) is generated by script, so there are **no models, no assets, and no manual building**.

## The loop
1. Run around a glowing night hub and **collect orbs** (Spark → Bloom → Nova → Mythic).
2. Chain pickups within 3 seconds to build a **combo** (up to x6).
3. Spend **Stardust** in the shop: Star Magnet, Comet Boots, Moon Jump, Orb Alchemy.
4. Step on glowing **launch pads** that fling you along a spiral of six sky islands; the higher you go, the richer the orbs.
5. **Ascend**: reset for a permanent +50% dust and a new aura/trail color. Then do it all faster.

Progress saves with DataStores (leaderstats show Stardust and Ascensions).

## Run it
**With Rojo (recommended)**
1. Install [Rojo](https://rojo.space) and run `rojo build -o StarlightSprint.rbxl` in this folder (or `rojo serve` and connect from Studio).
2. Open the place and press Play.

**Without Rojo** — in a blank Studio baseplate, create:
- `ReplicatedStorage > Shared` (Folder) containing a **ModuleScript** named `Config` ← `src/shared/Config.luau`
- `ServerScriptService` **Script** `Main` ← `src/server/Main.server.luau`
- `StarterPlayer > StarterPlayerScripts` **LocalScript** `Hud` ← `src/client/Hud.client.luau`

For saving in Studio, enable *Game Settings → Security → Enable Studio Access to API Services* (publish the place first).

## Tweaking
All balance lives in `src/shared/Config.luau` (orb values/rarity, upgrade costs, combo window, aura colors). Set `PickupSoundId` to any chime asset id to get a pitch-rising sound as your combo grows.
